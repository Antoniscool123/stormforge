# Stormforge

![build](https://github.com/Antoniscool123/stormforge/actions/workflows/build.yml/badge.svg)

A Fabric mod: relics forged from the heart of a storm.

## Content

Everything is in the **Stormforge** creative tab. Progress is tracked by a Stormforge advancement tab.

### Relics
| Item | Craft | What it does |
|---|---|---|
| **Storm Shard** | amethyst shard + lightning rod + gunpowder (makes 2), or mine Storm Ore | Crafting material |
| **Stormcaller Staff** | 3 shards + lightning rod + 2 blaze rods | Right-click: 5-bolt lightning barrage + shockwave at your crosshair (range 64). Sneak + right-click: one precise bolt. |
| **Rift Anchor** | 4 shards + 4 ender pearls + crying obsidian | Sneak + right-click: plant an anchor. Right-click: snap back to it (same dimension). |
| **Gale Feather** | feather + shard + breeze rod | Right-click: launch where you look, no fall damage. |
| **Storm Blade** | diamond sword + 4 shards + blaze rod | Diamond-tier sword. Hits apply Static Charge and arc lightning to up to 2 nearby creatures. |

### Tempest gear (netherite tier)
| Item | Craft |
|---|---|
| **Tempest Ingot** | 2 shards + 1 iron ingot (makes 2); repairs all Tempest gear |
| **Tempest Pickaxe / Axe / Shovel / Hoe** | standard tool patterns with ingots and sticks |
| **Tempest Helmet / Chestplate / Leggings / Boots** | standard armor patterns with ingots |

**Stormborn set bonus** (all four pieces): immune to lightning damage, permanent Speed I, and Resistance I + Regeneration I while in rain or a thunderstorm.

### Consumables and effect
- **Thunder Apple**: apple surrounded by 8 shards. Speed II, Absorption II and Resistance.
- **Storm Vial**: glass bottle + shard + sugar. Speed II and Jump Boost II for 4 minutes.
- **Static Charge** (effect): zaps once a second. Level II also arcs a weaker charge to nearby creatures (never players, and it cannot chain further).

### Blocks
- **Storm Ore** (underground, iron pickaxe, Fortune and Silk Touch work) and **Block of Storm Shards**.
- **Storm geodes**: rare underground geodes with stormstone, storm bricks, storm blocks, storm lamps and lightning rods inside.
- Building set: **Stormstone** (8 stone around a shard), **Polished Stormstone**, **Storm Bricks**, **Chiseled Storm Bricks**, **Storm Pillar**, stairs, slabs and walls for stormstone and storm bricks, **Stormglass**, **Storm Lamp**. Stonecutter recipes included.

## Build

Requires JDK 25 and Gradle 9.6+ (or generate a wrapper with `gradle wrapper`).

```
gradle build
```

The jar is in `build/libs/stormforge-1.0.0.jar`. Drop it in your `mods` folder with Fabric Loader and Fabric API.

## Regenerating assets

Models, loot tables, recipes, tags, advancements, worldgen and the placeholder textures for the
newer content are generated by `tools/gen_assets.py` (needs Pillow). Edit the script and re-run
`python3 -I tools/gen_assets.py` from the repo root rather than hand-editing those files.

## Version notes

Targets Minecraft 26.3 with Fabric Loader 0.19.5, Fabric API 0.162.0+26.3 and Loom 1.17.
Since 26.1 the game is unobfuscated, so the code uses Mojang names (`Item.Properties`,
`InteractionResult`, `ServerLevel`, ...) and there is no mappings line or `modImplementation`.
CI builds the mod and boots a dedicated server with it on every push, so data errors are caught before release (see the Actions tab); download the jar from the latest run's
`stormforge-jar` artifact.
